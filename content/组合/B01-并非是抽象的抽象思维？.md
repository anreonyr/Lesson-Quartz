# 并非是抽象的抽象思维？

## 导入

你想买一台电脑。

你爸说："自己装去！"

于是你开始研究电脑零件：处理器、主板、内存、硬盘、显卡、显示器、散热器、电源、键盘、鼠标、各种线......

面对这一堆零件，你可能会好奇：**为什么不同厂家的硬件拼在一起就能工作？**

因为**它们都遵循相同的多个标准**。

但光有标准还不够。这些硬件是怎么相互协调运行的？

我们先保留这个问题

## 抽象思维怎么用

回到组装电脑的例子。

一开始你看到的是：处理器、主板、内存、硬盘、显卡、显示器、散热器、电源、键盘、鼠标......

**抽象一下**：这些零件可以按功能分类

| 组件      | 功能   |
| ------- | ---- |
| CPU、GPU | 处理数据 |
| 内存、硬盘   | 保存数据 |
| 键盘、鼠标   | 接收指令 |
| 显示器     | 展示结果 |
| 电源、散热器  | 支持运行 |

这就是**从具体到抽象**——忽略具体型号，聚焦功能角色。

再进一步抽象：**计算机就是一个输入→存储→计算→输出的机器**

这就是[[示例-计算机体系结构#冯诺伊曼体系模型|冯诺依曼体系]]的核心，也是所有计算机的共同本质。

## 计算机的抽象层次

计算机系统有多个抽象层次[[示例-计算机体系结构#从盘古开天的抽象|计算机体系结构]]：

| 层次    | 关注点       | 抽象内容 |
| ----- | --------- | ---- |
| 硬件层   | 晶体管、电路    | 逻辑门  |
| 体系结构层 | CPU、内存、IO | 指令集  |
| 程序层   | 操作系统、应用   | 软件接口 |

**每一层只需要理解下一层提供的接口，而无需关心内部实现。**

#### 漫游计算机世界

如果你只可以看见每一个晶体管的状态，那么在人的视角你看到的计算机只是一堆密密麻麻跳变的开关，毫无规律，毫无意义

如果你再离得近亿点点，只看一定范围的晶体管，你可以看见输入一些电流信号可以输另一些电流信号，并且一个区域的输入和输出有规律

> 如果在计算单元你可以看见 1 + 1 = 10
> 如果你懂二进制的话 ;D

既然一定区域内是有规律的你又发现多个区域的信号交流似乎是在完成些什么

现在你开始把注意力放在不同区域的信号交流上，而不关心信号进入、出来的地方的细节

> 我编不下去了 ;v 机械降神！

如果你恰好把视线放在CPU，又恰好知道这个CPU的指令集

你就知道现在的CPU在执行什么指令、这些指令在执行什么算法，操作什么数据

再来如果你对这台计算机的所有硬件了如执掌，你就知道每一时刻每个部件在干什么

现在让你恢复正常人类的视觉，你现在能看见显示器、键盘、鼠标，最重要的是你可以玩游戏啦 ;P

如果你没有刚才的经历，你会觉得计算机是神奇的魔法

但现在你可以说，计算机的世界一切都是明确定义的

> 就连未定义边界的也是被人为定义的哦 ;D

这就是抽象的力量：让复杂的东西变得可以理解，因为你可以不关心那一堆二极管

## 问题

现在再回到导入的问题：**为什么不同厂家的桌面端硬件拼在一起就能工作？**

我们不需要深入到很深的层次，只需要到体系结构层和软件层。

硬件开发者们都会遵循通用的**接口标准**（如PCIe、USB、SATA等）。标准定义了硬件之间如何连接、如何通信，这是"能拼在一起"的基础。

通用的标准只会提供最基本的功能。硬件开发者还会依据自己开发的硬件的体系结构添加特有功能，这些功能需要安装额外的软件——没错，就是**驱动**。驱动是操作系统和硬件之间的"翻译层"。

## 思考题

> 练习抽象思维

1. **手机也是计算机**：尝试用"输入→存储→计算→输出"的框架分析手机，有哪些组件对应这些功能？

2. **网站是什么**：用抽象思维分析"访问一个网页"这个过程，忽略浏览器、服务器的具体实现，描述核心流程。

3. **分层游戏**：选择一个你熟悉的软件（比如微信、VS Code、游戏），尝试说出它有哪些抽象层次，每层依赖下一层的什么接口？

## 小结

> [!SUMMARY] 小结
> - **抽象思维 = 忽略细节 + 选择视角 + 整体把握**
> - 计算机系统本质：输入→存储→计算→输出
> - 抽象有层次，每层只关心下一层的接口
> - 会抽象，才能理解复杂系统
